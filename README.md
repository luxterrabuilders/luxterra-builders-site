# Luxterra Builders – Next.js Landing Page

Simple marketing site for Luxterra Builders (San Antonio and surrounding areas) built with Next.js (App Router) and plain CSS – no Tailwind required.

## How to use

1. Download and unzip this project.
2. Open a terminal in the project folder.
3. Install dependencies:

   npm install

4. Start the dev server:

   npm run dev

5. Open your browser at:

   http://localhost:3000

You can deploy this project directly to Vercel after pushing it to GitHub.
